# Correção ImportError - V21

## Correção rápida
Para o erro `cannot import name load_vu_excel`, substitua **pelo menos o `app.py`** do repositório pela versão V21.

A V21 não importa mais `load_vu_excel` de `src/excel_loader.py`. O suporte VU está dentro do próprio app.

## Recomendado
Substitua todo o conteúdo do repositório pela V21 para manter todos os arquivos sincronizados.

## Arquivo principal Streamlit
`app.py`
