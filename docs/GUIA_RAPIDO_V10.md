# Guia rápido — NIP Smart Distribuição V10

## Para distribuir obras

1. Abra a página **Início**.
2. Carregue a **BASE LIST.xlsx**.
3. Carregue a **PROJETISTAS.xlsx**.
4. Confira o resumo da equipe.
5. Clique em **GERAR DISTRIBUIÇÃO AUTOMÁTICA**.
6. Clique em **Baixar BASE LIST distribuída**.

A BASE original permanece intacta.

## Como interpretar a carteira

- **Sem obras**: o projetista ainda não possui obra `Em projeto` atribuída.
- **Precisa de mais obras**: já existe carga, mas ainda não cobre a referência de 30 postes / 5 projetos.
- **Carteira completa**: a carga atual cobre os dois objetivos.
- **Revisar PLN**: existe obra atribuída sem quantidade de postes confiável.

## Como interpretar produtividade

- **Fez no dia**: obras entregues na data selecionada.
- **Falta para a meta**: diferença para 30 postes / 5 projetos.
- **Estimativa até 18h**: projeção baseada no ritmo do dia quando a data analisada é hoje.
- **Precisa de atenção**: projetistas abaixo do ritmo, com falta de carga ou projetados abaixo da meta.

## O que é PLN

PLN é a quantidade de postes utilizada como peso da obra para a distribuição automática.

## O que a ferramenta não faz

- não analisa produtividade de levantadores;
- não reduz a meta do dia seguinte por causa de excedente anterior;
- não redistribui automaticamente uma obra que já possui projetista;
- não altera a BASE original no modo Excel.
